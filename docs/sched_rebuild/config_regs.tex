\begin{center}
{\LARGE\textbf{Config Register Reference --- AXI $\rightarrow$ DFI}}\\[2pt]
{\small One channel, DDR5. Every programmable config register (not runtime state).
\textbf{dom}: cfg=APB/config-clk, mc=\texttt{mc\_clk}(=dfi\_clk), ctrl=DFI control-clk, dev=DDR device.
\textbf{src}: APB=host bus, MR=DDR mode-reg (via MRR / vendor-set), PHY=PHY-provided, FSM=freq-change FSM.
All widths parametric.}
\end{center}

\vspace{3pt}
{\footnotesize \textbf{Update cadence summary:} \textbf{boot-once} = geometry, addr-map, feature enables,
scheduler tunables, thresholds. \textbf{DVFS / freq-change (quiesced)} = all timing consts, tphy\_*,
gear/freq-ratio, MR shadow (re-MRW), ODT. \textbf{MR-poll (runtime)} = rr\_shift / refresh\_mode
(from MR4 temp). \textbf{init (MRR read)} = RAAIMT/RAAMMT (vendor). \textbf{phyupd (PHY-initiated)} =
PHY may nudge tphy\_* / its own delays. Config is written by APB (host) or the freq-FSM; never by
traffic. All timing regs stay flops (freq-FSM writable) so they never constant-fold.}
