\section{Command interface (out unless noted)}
{\footnotesize \textbf{Note:} \texttt{cmd\_type} on the CA bus (via DFI\_CMD\_ENCODE) covers
\emph{all} CA opcodes --- demand (ACT/RD/WR/PRE) \emph{and} maintenance/power
(REF/REFsb/RFM/MRW/MRR/MPC/\textbf{SRE}/\textbf{SRX}/DES). The ME injects these into the bundle, so
power/maint \emph{commands} share the command phase. Only the pure CKE-level transitions
(power-down PDE/PDX, and CKE-low during self-refresh) ride \texttt{dfi\_cke} (POWER\_MGMT), not a CA
opcode. So power management uses BOTH: a CA command (encoder) + the CKE pin.}\\[3pt]
