\smallskip
{\footnotesize \textbf{CSn} (one-cold, active-low): ck0 selects target rank (rank0=L, rank1=H). ck1: ACT/MRW =H
(no-ODT 2-clk, note 11); WR/RD/MRR ck1 CSn on the \emph{non-target} rank = L to assert its ODT (note 8).
\textbf{ODT} \texttt{w} = asserted in the WL-aligned write window (ODT\_GEN), not fixed to the command beat.
\textbf{PAR} \texttt{P} = even parity over CA0..CA13 that beat. WR vs RD differ only at CA4 (rw picks it); \textbf{ap}=CA10 ck1.}
