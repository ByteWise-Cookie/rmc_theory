\emph{Consequence:} DDR3 has NO bank groups $\Rightarrow$ no S/L split $\Rightarrow$ the
\textbf{BGS/BGD scope tables collapse} and the \textbf{BG arb level disappears} (bank$\to$rank
directly). That is the single biggest structural change going DDR4/5 $\rightarrow$ DDR3.}

\section*{5. Port cost summary (what to touch)}
\textbf{DDR5 $\rightarrow$ DDR4:} params: N\_BANKS 32$\to$16, N\_BG 8$\to$4, BL 16$\to$8
(dqFree 8$\to$4), gear cap 1:4$\to$1:2, reload timing bin. \emph{Remove:} RFM/RAA engine,
REFsb + same-bank drain, tPPD, on-die-ECC assumption. \emph{Rewire:} ZQ (MPC$\to$ZQCL/CS),
CA-beat encoder (2-cyc$\to$1-cyc), INIT sequence. BG level \textbf{stays}.

\textbf{DDR4 $\rightarrow$ DDR3:} additionally set N\_BG 4$\to$1 $\Rightarrow$ \textbf{delete the
BG arb level, collapse BGS/BGD} into bank+rank, and drop all S/L timing splits (single tCCD/
tRRD/tWTR); remove DM/write-CRC; simpler ZQ; simpler init. Gear 1:1 only.

\textbf{DDR3 $\rightarrow$ DDR2:} N\_BANKS 8$\to$4/8, BL 8$\to$4/8; remove ZQ (OCD instead),
add AL (posted-CAS / additive latency into the timing model). Still no BG.

\textbf{DDR2 $\rightarrow$ DDR1:} N\_BANKS $\to$4, BL $\to$2/4/8; \textbf{remove tFAW} (4-bank,
no 4-ACT window), board-level ODT (no on-die), no AL. The arb tree is at its simplest:
bank$\to$rank only, no BG, no FAW.

\textbf{Stays parametric across all three (plug-and-play):} bank/rank counts, BL/dqFree,
timing CK values (from \texttt{timing\_reg\_file}), gear range, address-map slice, GC+comparator,
class-split arb, REFab, FAW window, turnaround (tWTR/tRTW), completion + data-path SRAMs.

\textbf{The irreducibly structural set (needs RTL, not a knob):} presence of the BG arb level +
S/L scoreboard, RFM engine, REFsb drain, the 2-cyc CA-beat encoder, and the ZQ/INIT command
encodings. Everything else is a parameter or a timing-reg reload.
